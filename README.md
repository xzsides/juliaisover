# juliaisover

A personal wallpaper collection, mostly illustration and anime art, picked for a clean **KDE Plasma + tiling** desktop with no icons or widgets.

Works on any distro (Gentoo, Arch, Fedora, NixOS, Void, and so on). It's just images.

## Contents

Most wallpapers are 1920x1080 (16:9). A few are higher resolution (up to 5120x2880).

## Usage

Clone the repo:

```bash
git clone https://github.com/xzsides/juliaisover.git
```

### KDE Plasma

1. Right-click the desktop and choose **Configure Desktop and Wallpaper**.
2. Set **Wallpaper Type** to **Slideshow**.
3. Add the cloned folder and pick an interval.

You can also give each virtual desktop its own wallpaper.
